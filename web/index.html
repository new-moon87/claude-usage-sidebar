Claude Code 의 남은 한도를 화면 가장자리에 얇게 붙여 둡니다. 마우스를 갖다 대면 자세히 펼쳐집니다.

버전 정보를 불러오는 중입니다.

표시하는 것

  • H — 5시간 세션 한도
  • W — 주간 한도 (전체 모델)
  • F — 주간 한도 (모델 전용, 계정에 따라 이름이 바뀝니다)
  • C — 추가 사용량 크레딧

Claude Code 데스크톱 앱을 켜면 저절로 나타나고, 끄면 사라집니다. 85% 를 넘긴 항목은 빨갛게 깜빡입니다.

설치

  1. 내려받은 zip 을 풀고 ClaudeSidebar.exe 를 실행합니다. 설치 과정은 없습니다.
  2. 파란 경고창이 뜨면 추가 정보 → 실행. 코드 서명 인증서가 없어서 뜨는 것입니다.
  3. Claude Code 에 한 번 로그인해 두어야 네 항목이 모두 나옵니다. 로그인 이력이 없으면 패널의 “Claude 로그인 필요” 를 눌러 터미널을 열 수 있습니다.

필요한 것

  • Windows 10 이상 (64비트)
  • .NET 8 데스크톱 런타임 — 없으면 아래 한 줄로 설치합니다. 
    winget install Microsoft.DotNet.DesktopRuntime.8
  • Claude Code (데스크톱 앱 권장 — 자동 표시/숨김이 이 앱 실행을 보고 판단합니다)

명령 한 줄로 설치하기

Node 가 있다면 내려받기 없이 바로 설치·실행할 수 있습니다.

npx github:new-moon87/claude-usage-sidebar install

한 번 설치하면 그 뒤로는 새 버전이 나올 때 시작하면서 스스로 갱신합니다. 이 페이지를 다시 찾아올 필요가 없습니다.
